# Subliminax

Psychoacoustic and subliminal soundtrack studio — React, TypeScript, Tailwind CSS, Web Audio API.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://127.0.0.1:5173`).

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Dev server |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Preview production build |
| `npm run lint` | Oxlint |

## Architecture

See Project docs: `docs/subliminax-studio.md` in the agent store.
